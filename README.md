# Bezier Surface
Project rendering animated Bezier Surface in 3D according to 16 Control Points, with rotation ability.
Surface is interpolated using triangular mesh.

User Features
- Ability to modify normal vectors using a Normal Vector Map.
- Option to load custom textures.
- Changing light parameters

Lighting
- Spotlight: Dynamic and directional light source.
- Standard Light: Basic point light source.

Models and Algorithms
- Lighting Model: Phong Lighting Model.
- Shading: Phong Shading Algorithm.
